# Customer Retention & Churn Analysis

## Project Overview

This project analyzes customer churn behavior using Python and SQL techniques. The objective is to identify the factors that contribute to customer churn and provide business recommendations to improve customer retention.

## Dataset

* **Dataset:** IBM Telco Customer Churn Dataset
* **Number of records:** 7,043 customers
* **Number of features:** 21 columns

## Tools Used

* Python
* Pandas
* Matplotlib
* SQLite
* Google Colab

## Project Workflow

1. Data Loading
2. Data Cleaning
3. SQL Analysis
4. Exploratory Data Analysis (EDA)
5. Data Visualization
6. Business Recommendations
7. Conclusion

## Key Findings

* Month-to-month customers have the highest churn rate.
* Customers with shorter tenure are more likely to churn.
* Higher monthly charges are associated with higher churn.
* Electronic check users show a higher churn rate.

## Business Recommendations

* Encourage customers to switch to long-term contracts.
* Offer retention programs for new customers.
* Promote value-added services such as Tech Support and Online Security.
* Improve the payment experience for electronic check users.

## Conclusion

This project utilized both Python and SQL to analyze customer churn behavior using the IBM Telco Customer Churn dataset. SQL was used to query and summarize customer information, while Python was used for data cleaning, exploratory data analysis (EDA), and data visualization.
The analysis revealed that customers with month-to-month contracts, shorter tenure, higher monthly charges, and electronic check payment methods are more likely to churn. These findings provide valuable insights into customer behavior and can help businesses develop targeted retention strategies, improve customer loyalty, and make more informed, data-driven decisions.
